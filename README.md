# THE LAST TEN MINUTES

A compact first-person psychological horror game set inside Morrow Research Station.

## Play
Open `index.html` in a modern browser. Internet access is required for Three.js CDN modules and Google Fonts.

### Controls
- WASD — move
- Mouse — look
- Shift — sprint
- Ctrl — crouch
- E — interact
- F — flashlight
- Tab — notebook
- Q / E — lean (reserved for future contextual lean)
- Esc — pause / release mouse

## Core systems
- Ten-minute reconstruction loop
- Persistent knowledge and notebook
- Perception instability and controlled anomalies
- Witness perception / investigation / stalking AI
- CCTV narrative event
- Radio narrative system
- Physical-feeling interactions
- Fuse → badge → archive → core progression
- Multiple diegetic ending choices
- Local persistence via browser storage

## Design intent
The game is deliberately compact rather than open-world. The facility is interconnected and authored around repeatable routes, anomalies, and escalating observation. The central rule is: **the loop is learning you.**
